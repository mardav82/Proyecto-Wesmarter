# Centro de Kinesiología Esther Ofman - Sitio Web

Sitio web institucional del centro de kinesiología y rehabilitación Esther Ofman, ubicado en Almagro, Capital Federal.

## Estructura del proyecto

- index.html — Página principal
- motora.html — Reeducación Postural
- neurologica.html — Neurología
- respiratoria.html — Fisioterapia y Rehabilitación
- traumatologica.html — Traumatología
- css/ — Archivos de estilos
- js/ — Scripts JavaScript
- imagenes/ — Imágenes del sitio
- obras_sociales/ — Imágenes de obras sociales

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Swiper.js (carrusel de imágenes)
- OpenWeatherMap API (clima en tiempo real)
- Google Fonts
